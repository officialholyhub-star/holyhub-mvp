# Deepgrids Sans

These are the supplied Deepgrids Sans variable font files, copied without modification.
Both identify their family as Deepgrids Sans and support weights 300–900.
The primary Latin file is preloaded; the Latin Extended file is a local fallback.
No third-party font requests are made by visitors.
